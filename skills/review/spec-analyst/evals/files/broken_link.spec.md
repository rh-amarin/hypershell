# Gateway Telemetry Specification

**Date:** 2026-08-22
**Status:** Active
**Parent:** openshell-nonexistent-parent.spec.md

## Purpose

Defines telemetry emitted by a gateway. See the base contract in
[gateway base spec](./gateway-base-does-not-exist.spec.md) and the routing rules
in `openshell-gateway-routing.spec.md` § Nonexistent Section Heading.

## Requirements

### Requirement: Telemetry Emission

A gateway SHALL emit request-latency telemetry through the platform observability
port described in [observability](./api-server-observability.spec.md).
